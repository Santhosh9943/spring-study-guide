# Contributing

Thanks for your interest! Here's how to help:

## Reporting Issues
- Typos, broken links, or incorrect content → open an issue with the file path and section.

## Suggesting Improvements
- Open an issue describing the change.
- Or submit a PR with a clear description.

## Pull Request Process
1. Fork the repo.
2. Create a branch: `git checkout -b fix/section-name`.
3. Make your changes.
4. Update the README if needed.
5. Submit a PR — one change per PR please.

## Style Guide
- Use standard Markdown.
- Keep code examples runnable.
- Follow the existing section structure.

Thank you! 🌱
