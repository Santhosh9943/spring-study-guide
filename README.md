## 📖 About

This repository contains **27 in-depth markdown files** covering the entire Spring ecosystem — Core IoC/DI, AOP, MVC, JDBC, Transactions, Spring Boot, JPA, Security, Testing, Maven, Microservices, WebFlux, Batch, Messaging, and interview prep.

Each file is **self-contained** with full explanations, code examples, diagrams, and interview notes.

## 🚀 How to Use

1. **Clone the repo:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/spring-study-guide.git
   ```
2. **Read on GitHub** — click any link above.
3. **Read locally** with VS Code, Obsidian, or Typora.
4. **Follow the study path** in order (01 → 27).
