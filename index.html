    🌱 Spring Ecosystem Study Guide¶

    A complete, hands-on study guide for the Spring Framework ecosystem — from core concepts to production-ready microservices.

    📖 About¶

    This repository contains 27 in-depth markdown files covering the entire Spring ecosystem — Core IoC/DI, AOP, MVC, JDBC, Transactions, Spring Boot, JPA, Security, Testing, Maven, Microservices, WebFlux, Batch, Messaging, and interview prep.

    Each file is self-contained with full explanations, code examples, diagrams, and interview notes.

    🗺️ Study Path¶

    Phase Weeks Part Focus
    1. Foundations 1–4 Part 1 Core, AOP, MVC, JDBC, TX
    2. Spring Boot 5–7 Part 2 Boot, Starters, Config, Actuator
    3. Data & Security 8–11 Parts 3–4 JPA, Caching, Security
    4. Testing & Build 12–13 Parts 5–6 Testing, Maven, Gradle
    5. Advanced 14–18 Part 7 Microservices, WebFlux, Batch
    6. Interview Prep 19–20 Part 8 Questions, Architecture

    🚀 How to Use¶

    1. Clone the repo: 
      git clone https://github.com/YOUR_USERNAME/spring-study-guide.git
    2. Read on GitHub — click any link above.
    3. Read locally with VS Code, Obsidian, or Typora.
    4. Follow the study path in order (01 → 27).

    🛠️ Prerequisites¶

    • Java 17+ (21 recommended)
    • Maven 3.9+ or Gradle 8+
    • Basic Java/OOP knowledge
